# 健身记录 v2

按新版 Figma 设计重做的健身记录 App（网页版）。

- 首页：今日训练计划、本周排期、动作清单、热身建议
- 训练：训练计时、组间休息倒计时、重量/次数记录、热身组/递减组标记、动作库选择
- 记录：训练次数、总容量、时长统计；按日汇总、个人纪录
- 设置：五分化/推拉腿/上下肢等排期模板、动作库管理、训练偏好

数据仅保存在浏览器本地（IndexedDB），不会上传到任何服务器。

## 本地运行

```bash
npm install
npm run dev
```

## 发布到 GitHub Pages

推送到 `main` 分支后，GitHub Actions 会自动构建并发布到 Pages。
